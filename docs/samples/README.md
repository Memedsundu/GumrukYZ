# Örnek belge paketleri (pilot)

Bu klasör pilot firmalara verilecek **anonimleştirilmiş PDF** örneklerini barındırır.

## Şu an

- `fixtures/` altındaki JSON dosyaları kural testleri içindir (PDF değil).
- Pilot öncesi buraya en az bir **redakte edilmiş paket** ekleyin:
  - `pilot-import-clean/` — fatura, çeki listesi, konşimento, beyanname çıktısı (metin tabanlı PDF)

## Firmalara iletilecek mesaj

> Mümkünse kendi anonimleştirilmiş belgelerinizi kullanın. Örnek paket yalnızca akışı denemek içindir; gerçek müşteri verisi yüklerken uygulamada **Gerçek müşteri belgesi** seçeneğini işaretleyin ve pilot koşullarını onaylayın.

Ayrıntılı akış: [pilot-firm-onboarding.md](../pilot-firm-onboarding.md)
